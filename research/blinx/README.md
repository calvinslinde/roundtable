# Blinx study notes

These notes record how the visual language of *Blinx: The Time Sweeper* (Artoon, 2002) works, as reference for the generator's own art direction.

The video frames and crops the notes cite (`frames/`, `crops/`) were removed from this repository on 2026-10-18: they are captures of the game itself, which is copyrighted. The notes are original analysis and remain. `tools/sample.py` expects the crops and will not run without them.
